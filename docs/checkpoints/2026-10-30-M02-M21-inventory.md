## 3. M21 current state

- Principal-to-tenant grants already exist as `finance_integration_tenant_grants` with composite primary key (principal_id, tenant_id).
- One principal can access multiple tenants; multiple principals can be granted to a tenant.
- The middleware validates client ID, bearer secret digest, required scopes, explicit tenant grant and active tenant.
- `backend/src/modules/integrations` and `frontend/src/features/integrations` are currently skeletons.
- No external company reference model (consumer system + external company ID) was found in the 22 migration files or the inspected integration module.
- No tenant-to-jurisdiction applicability association table was found.

## 4. Confirmed missing data model

The tenant foundation only stores legal_name, country_code and default_currency. The registration request repeats these three fields. It does not yet provide a complete tenant company profile with commercial name, registered address, timezone, languages and typed tax/regulatory identifiers.

Customer addresses are not company addresses: `finance_customer_addresses` belongs to `finance_customers` and must not be repurposed.
